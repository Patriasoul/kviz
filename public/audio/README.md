# PatriaSoul quiz music

Place the licensed MP3 files in this directory with exactly these filenames:

- `legionnaire.mp3` — **Legionnaire (Original)** — Scott Buckley
- `dystopia.mp3` — **Dystopia** — Per Kiilstofte / Machinimasound
- `the-constellation.mp3` — **The Constellation** — Hayden Folker

## Usage in the app

- `croatian` → Legionnaire
- `city` → Dystopia
- `daily` → The Constellation

The application falls back to its generated ambient motif if an MP3 is not present.
