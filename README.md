# PatriaSoul — Hrvatski kviz 🇭🇷

Samostalna web aplikacija za PatriaSoul kvizove.

## Trenutno
- početni ekran i izbor kategorije
- igra s 4 odgovora
- odbrojavanje 20 sekundi po pitanju
- bodovanje i indikator napretka
- ekran rezultata
- početna stranica rang-liste
- odvojena baza pitanja u `data/questions.js`

## Kategorije
Hrvatsko opće znanje, Povijest, Domovinski rat, Geografija Hrvatske, Kultura i baština i Glagoljica.

## Sljedeća faza
1. Uvoz postojećih 800 pitanja bez izmjene sadržaja.
2. Dodavanje novih 1200 pitanja.
3. Trajno spremanje rezultata i prava rang-lista.
4. Administracija baze pitanja.
5. Brani svoj grad.
6. Povezivanje s PatriaSoul portalom preko gumba **Igraj kviz**.

Aplikacija je namjerno napravljena bez frameworka kako bi temelj bio jednostavan za održavanje i kasnije proširenje.
